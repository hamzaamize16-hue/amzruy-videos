# EP02 : La khettara, comment un trou dans le désert devient une rivière souterraine

Format inspiré des explainers low-poly 3D (« How a hole becomes… »). Hook : question / transformation.

## Texte voix (une ligne = une scène)

1. كيفاش حفرة صغيرة فالصحرا… كتولي واد كيجري تحت الأرض؟
2. فالجنوب، الشمس كتشرب الما قبل ما يوصل للفلاحة.
3. داكشي علاش جدودنا حفرو بير لتحت… حتى لقاو الما.
4. ومن بعد، بير ورا بير، فخط واحد كينزل شوية بشوية.
5. وفلقاع، ربطوهم بنفق… بلا موتور، غير بالميلان.
6. الما كيجري بوحدو، والشمس ما كتوصلوش.
7. وفالأخير كيخرج للسطح… وكتحيا الواحة.
8. هادي هي الخطارة! تقنية جات مع المرابطين لمراكش… وفالسبعينات، كانت فالحوز خمسمية وسبعة وستين خطارة!
9. والمفاجأة؟ اليوم فمراكش، تقريبا كاملين نشفو.
10. واش عمرك شفتي خطارة بعينيك؟ كتب لينا فين فالكومونتير… وتبعنا.
